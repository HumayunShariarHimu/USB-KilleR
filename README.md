## 🔩 উপাদানের তালিকা (Bill of Materials - BOM)

| কম্পোনেন্ট | মান/মডেল | পরিমাণ | কাজ |
| :--- | :--- | :--- | :--- |
| **F1** | পলিসুইচ (৫০০mA) | ১ | ওভারকারেন্ট প্রোটেকশন |
| **C1** | ১০০µF / ১৬V | ১ | ইনপুট লাইন ফিল্টার |
| **Q1** | IRFZ44N (N-MOSFET) | ১ | বুস্ট কনভার্টার সুইচ |
| **L1** | ২২µH / ৩A | ১ | এনার্জি স্টোরেজ ইনডাক্টর |
| **T1** | ফ্লাইব্য্যাক ট্রান্সফরমার (১:২০) | ১ | স্টেপ-আপ ভোল্টেজ রূপান্তর |
| **D1-D10** | UF4007 / MUR460 | ১০ | রেকটিফিকেশন ও মাল্টিপ্লায়ার ডায়োড |
| **C3-C14** | ২.২nF / ২kV (সিরামিক) | ১২ | হাই-ভোল্টেজ স্টোরেজ (মাল্টিপ্লায়ার) |
| **R3** | ২০MΩ / ২W | ১ | ব্লিডার রেজিস্টর (নিরাপদ ডিসচার্জ) |
| **IC1** | ATtiny85 | ১ | PWM জেনারেশন, সেন্সিং, টাইমিং |
| **Gate Drv.** | TC4420 | ১ | MOSFET গেট ড্রাইভার (৩A পিক) |
| **Q2-Q4** | FQPF9N50C (৫০০V) | ৩ | মাল্টি-পিন ডিসচার্জ সুইচ (D+, D-, VBUS) |
