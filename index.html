SAFETY / RESPONSIBLE RESEARCH

The repository is explicitly a research-based project and the board marking indicates a high-voltage output. Never connect it to people, production hardware, or unknown USB ports. Do not energize without appropriate isolation, current limiting, enclosure, qualified supervision and local electrical-safety compliance. The functional description above distinguishes exact file metadata from engineering inference; validate every revision in a controlled lab before use.
